# 旅のしおりサービス競合分析

## 既存サービス比較

| サービス | 状況 | 特徴 |
|---|---|---|
| 行程さん | 終了 | リアルタイム「next」表示・印刷品質高 |
| Pen | 終了 | DAY1/DAY2タブジャンプUI・シンプル |
| 旅しお | 運営中 | PDF印刷・共同編集あり |
| しおりす | 運営中 | ファイル添付・3色テンプレート |
| tabiori | 運営中 | コンビニ印刷・位置情報共有・全員登録必要 |
| タビカンジ | 運営中（最推奨） | デザイン性高・6種シェア・3段階パスワード |

## しおりの標準コンテンツ構造

```
しおり全体
├── タイトル
├── 旅行期間
└── 日付ごとのブロック（DAY1, DAY2...）
    └── 予定アイテム
        ├── 時間（何時〜何時）
        ├── 場所・内容テキスト
        ├── アイコン（交通手段、食事など）
        ├── リンクURL
        └── 画像添付（一部のみ）
```

## ユーザーが求める機能（優先度順）

### 必須
- 会員登録不要
- リンクで共有
- 合言葉で共同編集
- **ドラッグ＆ドロップ並び替え**（全サービス未対応 → 最大の差別化ポイント）
- 時間設定（何時〜何時）
- リンク添付
- アイコン選択（交通手段・食事等）
- スマホ・PC両対応

### あれば嬉しい
- 印刷が綺麗
- 画像添付
- **現在時刻に応じた「next」表示**（行程さん終了後に誰も実装していない）
- **日付タブジャンプ**（Pen終了後に誰も実装していない）
- デザインテンプレート選択

## 競合の弱点（差別化チャンス）

1. **D&Dが全サービス未対応** - 並び替えが上下ボタンで不便
2. **サービス終了リスク** - ユーザーが最も恐れている（行程さん・Pen終了）
3. **モバイル未対応** - 旅しおはスマホ表示崩れ

## AIによる自動生成の差別化

現存サービスはすべて手動入力。AIで自動生成するのは唯一の存在になれる可能性あり。

## 次フェーズの実装優先度

1. しおり形式のUI（DAYタブ、時間タイムライン）
2. ドラッグ＆ドロップ編集
3. 「次の予定」リアルタイム表示
4. 印刷/PDF出力
5. 共同編集（パスワード保護）
